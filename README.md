# Carrinho de Compras 🛒
Uma aplicação web que simula um carrinho de compras de um e-commerce, desenvolvida com **React** e **Vite**. Este projeto foi criado para praticar conceitos de gerenciamento de estado, design responsivo e interações dinâmicas.

## 🚀 Visite o Projeto
Confira o deploy no Vercel: [Carrinho de Compras](https://carrinho-de-compras-peach.vercel.app/)

## 🛠️ Tecnologias Utilizadas
- **React**: Biblioteca JavaScript para construção de interfaces.
- **Vite**: Ferramenta de build rápida e moderna.
- **CSS Modules**: Para estilização modularizada.
- **Vercel**: Hospedagem e deploy do projeto.

## ✨ Funcionalidades
- **Adicionar Produtos**: Adicione produtos ao carrinho de compras.
- **Remover Produtos**: Remova produtos do carrinho de compras.
- **Total da Compra**: Visualize o valor total da compra.
- **Design Responsivo**: Funciona bem em dispositivos móveis, tablets e desktops.

## 🎯 Objetivo
O objetivo do **Carrinho de Compras** é proporcionar uma experiência de compra simples e eficiente, com foco em boas práticas de design e usabilidade. Este projeto também serve como um exemplo de como implementar gerenciamento de estado e design responsivo com React.
